# Alerta de chamada por Bluetooth
Ao receber uma ligação via WhatsApp, o app envia a informação via bluetooth para o HC-05 conectado ao Arduino, que aciona um buzzer e mostra quem está ligando em um display.

# Materiais:
- Arduino UNO
- Módulo Bluetooth HC-05
- Buzzer
- Display LCD 16x2
- Resistores
- Jumpers
- Protoboard
- Cabo USB

# Programas usados
- Arduino IDE (C++)
- MIT App Inventor
